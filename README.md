Getting started (development)

Prerequisites
- Node.js (16+) and npm

Install and run locally

```bash
npm install
npm run dev
```

Build for production

```bash
npm run build
```

Project structure
- `index.html` — app entry
- `src/` — React source files
	- `main.jsx` — app bootstrap
	- `App.jsx` — root application component
	- `pages.jsx` — routes / page components
	- `styles.css` — global styles
- `public/assets/images/` — image assets

Deployment
- This project builds to a static bundle that can be deployed to GitHub Pages, Vercel, Netlify, or any static host.

Thanks for considering contributing to this portfolio!

How to contribute
- Fork the repository and open a pull request with focused changes.
- Keep PRs small and include a short description of the change and why it helps the portfolio.
- For code changes, include a screenshot or short video if the change affects visuals.

Areas that welcome contributions
- Project showcase content and case studies
- Accessibility and responsive improvements
- Small UI/UX polish and performance tweaks

Review process
- I will typically accept small, well-scoped PRs within a few days. For larger changes, please open an issue first to discuss the approach.
